## 如何使用候选

| 状态 | 动作边界 |
| --- | --- |
| 止跌候选，核验基本面 | 只代表价格开始修复；先查最近财报、指引、分析师预期和资产负债表，再决定是否建立研究仓 |
| 反弹过快，等待回踩 | 5日反弹或高于MA20距离触发追涨阻断；不在加速段追入，等待缩量回踩后重新评分 |
| 初步止跌，继续观察 | 修复信号不足；等待更高低点、站回20日均线或相对板块转强 |
| 继续下跌，暂不接 | 深度回撤但没有价格确认；不要因为便宜一路摊平 |
| 极端回撤，先排雷 | 先排查业绩下修、融资、会计、诉讼、监管和流动性风险 |

## 计算口径

- `60日高点回撤`：最新收盘相对最近60个交易日最高收盘的跌幅；不是盘中最大回撤。
- 少于60个可比收盘、行情日期滞后或存在未解释的单日异常跳变时，不计算候选分，也不进入候选表。
- 已知拆股、分拆等公司行动默认只使用生效日之后的数据重新累计；样本不足时继续阻断。
- `20日下跌天数`：最近20个交易日中收盘低于前一日的次数；最长连跌只作辅助，避免漏掉反复下跌的 COHR 型走势。
- `近5日低点抬高`：最近5个收盘价的最低值高于此前5个收盘价的最低值。
- `相对基准`：个股同期收益减去配置中的行业 ETF 或 VOO 收益；不是风险调整后超额收益。
- `形态分`：回撤20分、下跌密度10分、RSI超卖5分、价格修复25分，总分60；高分不等于公司质量高。
- `研究层级`：只有价格门禁、人工基本面复核和事件门禁同时通过才标为“可研究”；没有基本面复核的一律只是“仅技术观察”。
- `事件/追涨阻断`：默认未来7天内有已知事件、5日反弹达到15%，或价格高于MA20达到10%时阻断，不给出建仓动作。
- RSI14 使用 Wilder 平滑法；与不同复权口径的行情软件仍可能存在差异。
- 财报、公司行动和公司事件目前采用配置中的人工维护清单并辅以价格跳变报警；没有自动数据时显示“待人工核验”。

## 人工基本面核验清单

1. 最近一季营收、毛利率、自由现金流和指引是否恶化。
2. 下跌是估值压缩、板块风险偏好变化，还是公司逻辑失效。
3. 未来30天是否有财报、解禁、诉讼、监管决定或融资。
4. 写下逻辑失效条件、最大总仓位和单笔组合风险，再考虑首笔研究仓。
